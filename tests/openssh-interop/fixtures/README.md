# OpenSSH-interop fixtures

This directory holds **deterministic** test material consumed by both the
Docker compose stack and the Rust test harness.

## Layout

```
fixtures/
  keys/                       # client-side keypairs the spt binary will use
    test_ed25519             # ED25519 private key (mode 0600)
    test_ed25519.pub
    test_rsa                 # RSA-3072 private key (mode 0600)
    test_rsa.pub
  host_keys/                  # sshd host keys mounted into the containers
    ssh_host_ed25519_key
    ssh_host_ed25519_key.pub
    ssh_host_rsa_key
    ssh_host_rsa_key.pub
```

## Regenerating

The keys are generated by `gen-fixtures.sh` (POSIX sh, requires
`ssh-keygen`). The script is idempotent — re-running it overwrites the
existing files.

```sh
cd tests/openssh-interop/fixtures
sh gen-fixtures.sh
```

CI regenerates fixtures on every run because the resulting fingerprints
are read at test time, not pinned in source. Committing them is optional;
the `.gitkeep` files preserve directory structure.

## Pin fingerprints

`pinning.rs` reads the actual fingerprint from `host_keys/*.pub` at test
time using `ssh-keygen -lf`. There is intentionally no hard-coded SHA256
in source — keys can be regenerated without code changes.
